NewBoxofficeProject

End-to-End Data Pipeline, Relational Modeling & Box Office Intelligence Platform

NewBoxofficeProject nasce per risolvere la frammentazione dei dati nel settore cinematografico. Il progetto implementa un'architettura completa per estrarre, normalizzare, memorizzare e analizzare in modo strutturato gli incassi al botteghino (weekend, settimanali, stagionali) e le performance dei distributori.

01

Data Ingestion

Estrazione automatizzata da fonti eterogenee del box office e feed dati strutturati.

02

Cleaning & ETL

Normalizzazione di valute, formati data, mapping dei generi e rimozione duplicati con Python & Pandas.

03

Relational Database

Schema SQL ottimizzato (Tabelle Film, Incassi, Sale, Distributori) con indici analitici.

04

Analytics & KPI

Query complesse, calcolo del multiplier di longevità, quote di mercato e trend temporali.

10K+ Record & Incassi Tracciati
100% Integrità Referenziale SQL
4 Dim. Analisi (Tempo, Genere, Distributore, Budget)
Python SQL (PostgreSQL/MySQL) Pandas ETL Architecture Data Modeling Data Analytics

Dettagli Strutturali dello Schema Dati

Lo schema adotta una modellazione a stella/fiocco di neve semplificata per massimizzare la velocità di aggregazione:

  • Fact Table: fact_boxoffice_weekly (foreign key su film, data, sala, incasso netto, presenze).
  • Dimension Tables: dim_movies, dim_distributors, dim_theaters, dim_dates.
  • Pipeline di Aggiornamento: Script Python schedulato che esegue validazione di schema, de-duplicazione e upsert incrementale.
